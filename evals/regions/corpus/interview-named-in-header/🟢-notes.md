# interview-named-in-header

Transcript. The interviewee is named once in the header, then twenty lines of Q and A.

- Person 🟢 — twelve regions alternating `interviewer` and `okafor`, boundaries exact.
- Date 🟢 — the header date owns the whole interview.

All clean, and better than expected: attribution reached from the header because the whole document fits in one find call. A document large enough to split would not have that, so this file does not prove the long-range case.
